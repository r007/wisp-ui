# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
By participating, you agree to uphold it.

In short: be respectful and constructive, assume good faith, and keep discussion
about the work. Harassment, discrimination and personal attacks are not
acceptable.

## Reporting

Report unacceptable behaviour privately to the maintainers through GitHub
(contact the repository owner via their profile). Reports are handled
confidentially.
